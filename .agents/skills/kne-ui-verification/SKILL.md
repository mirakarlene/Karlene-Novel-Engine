# Проверка UI KNE

Прочитай [AGENTS.md](../../../AGENTS.md). Проверяй экраны, элементы и поведение из запроса. Для правок дизайна требуется явное указание пользователя. Проверка или найденный дефект в соседнем элементе сами по себе такого разрешения не дают. При неоднозначности покажи пользователю конкретные варианты и проверяй независимые части, пока он выбирает. Если требуется восстановить прежний вид, сравнивай с соответствующей версией в Git.

## Подбор проверки

| Что изменилось | Существующее покрытие |
| --- | --- |
| «Параметры проекта» или «Параметры сцены» | [CompactParameterWindowsTests](../../../tests/KNE.Tests/CompactParameterWindowsTests.cs) проверяет страницы, доступность условных полей и отсутствие обрезания. Размеры проекта 780×840 и 740×680, размеры сцены 780×640 и 740×600. |
| Настройки KNE и режимы коррекции цвета | [AccessibilityUiTests](../../../tests/KNE.Tests/AccessibilityUiTests.cs) проверяет минимальный размер и применение настроек. Для имён элементов, цвета и различимости категорий см. [kne-ui-accessibility](../kne-ui-accessibility/SKILL.md). |
| Запуск игры, меню, окно рантайма или расположение элементов сцены | [EngineWindowTests](../../../tests/KNE.Tests/EngineWindowTests.cs) проверяет запуск, меню и начальный размер. [GameplayUiTests](../../../tests/KNE.Tests/GameplayUiTests.cs) проверяет компоновку сцены, диалога и зон клика. |
| Встроенный предпросмотр | [ScenePreviewUiTests](../../../tests/KNE.Tests/ScenePreviewUiTests.cs) проверяет ресурсы темы, спрайт и диалог на реальном WPF-экране предпросмотра. |
| Масштабирование слоя с анимированным фоном и шейдером | [WavePostProcessingTests](../../../tests/KNE.Tests/WavePostProcessingTests.cs) проверяет обновление текстур при изменении размера. Для этого случая включи `KNE_GPU_TEST=1` при наличии подходящего Windows GPU. |

Выполняй целевые тесты из корня репозитория на Windows. Пример для окон параметров:

~~~powershell
dotnet test tests/KNE.Tests/KNE.Tests.csproj -c Release --filter 'FullyQualifiedName~KNE.Tests.CompactParameterWindowsTests'
~~~

При необходимости сохрани снимки во временный каталог через уже поддерживаемые переменные `KNE_COMPACT_RENDER` для компактных окон, `KNE_RENDER_DIR` для тестов игрового окна и `KNE_EDITOR_RENDER` для предпросмотра и поддерживающих его тестов редактора. Укажи абсолютный путь к каталогу. Снимок подтверждает визуальную проверку после просмотра. Результат теста подтверждает только его утверждения.

## Что проверить на экране

- Открой затронутый экран при обычном и минимальном поддерживаемом размере. Проверь видимость подписей, отсутствие перекрытий и обрезания, переходы между страницами и результат действия. Для русских подписей используй реальные длинные строки. При изменении поведения проверь применимые состояния, например недоступный контрол или отмену.
- При изменении рантайма различай размер окна Windows, клиентскую область и логический холст сцены 1280×720. При необходимости сравни DPI и форматы с разными пропорциями. Проверяй области клика по измеренной сцене после масштабирования.
- В отчёте или PR укажи экран, размер и DPI, если он влиял на результат, выполненное действие и наблюдение. Перечисли запущенные тесты и существенные пропуски. Отдельно отметь сценарии, для которых удалось проверить только разметку или тестовые утверждения.
